# Reproducing BioPhasor

Every number and figure in the manuscript is regenerated by one command from
public data (GEO, CPTAC), with documented defaults and no tuning to any
evaluation reference.

## 1. Environment (pinned)

```bash
make env        # creates .venv, installs requirements-lock.txt, then `pip install -e .`
make check      # verifies interpreter, biophasor import, and data presence
```

- Python 3.11 (tested 3.11.15). Core deps and exact versions are pinned in
  [`requirements-lock.txt`](requirements-lock.txt).
- Benchmark comparisons additionally use `mofapy2`, `snfpy`, `tensorly`,
  `lifelines`, `CosinorPy` (all in the lockfile).

## 2. Data

| Scenario | Accession | Retrieval |
|---|---|---|
| scRNA-seq (encoding, cell-cycle, Kuramoto, manifold, attractor) | GEO **GSE293316** (REH B-ALL 10x) | NCBI GEO |
| Circadian time-series | GEO **GSE171432** (WT + Bmal1-KO mouse liver) | NCBI GEO |
| Matched multi-omics (fusion, classification, CST, PAC, quantum) | **CPTAC UCEC** | `cptac` package (`cptac.Ucec()`) |
| Hard-task clinical labels (grade, histologic type) | CPTAC UCEC clinical (`mssm` source) | `cptac.Ucec().get_clinical("mssm")` |

Datasets cache under `experiments/data/raw/`. `make check` fails early with a
clear message if any file is missing.

## 3. Run everything

```bash
make reproduce      # == bash reproduce.sh
```

Each `experiments/codes/expNN_*.py` writes a results JSON to
`experiments/results/` and figures to `experiments/figures/` and `manuscript/`.

## 4. Known numerical workaround (tensorly complex TT-SVD)

`tensorly` 0.9.0 accepts a complex tensor in `tensor_train` but its complex
TT-SVD is numerically unreliable on this data (reconstruction error *increases*
with bond dimension). Every tensor-train decomposition therefore operates on a
**real/imaginary-stacked** representation of the complex CST (a size-2 trailing
axis), not the complex tensor directly. This is implemented and documented in
`experiments/codes/exp07_cst_tensornetwork.py` (see the module docstring).

## 5. Tests

```bash
make test           # 96 tests incl. coherence-gated fusion property tests
```

## 6. Release checklist (for a citable archive)

- [ ] Tag a release and mint a **Zenodo DOI** (GitHub→Zenodo integration).
- [ ] Confirm the manuscript bibliography builds from `references.bib` on a
      clean checkout (`mainNotes.bib` must be non-essential / removed).
- [ ] Verify **license compatibility** with the target venue: the code is
  Apache-2.0; several journals (PLOS, eLife) require CC-BY for the
      article and permissive/OSI licenses for code — resolve before submission.
- [ ] Pin the `cptac` package version actually used (its bundled data revision
      changes over time; record it in `requirements-lock.txt`).
